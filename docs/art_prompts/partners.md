# 동료 페어리 11인 - 캐릭터 시트

- 저장 폴더: `assets/characters/partners/`
- 외형 원칙: 모든 동료는 요정 형태이며, 외형 컨셉은 기획서 5장의 속성 색상과 스킬 컨셉에서 도출한다.
- 공통 블록(STYLE_BASE, VIEW, LAYER) 및 작업 규칙은 `docs/art_style_guide.md`를 따른다.
- 동료별 IDENTITY / OUTFIT / PALETTE / POSE 블록은 외형 컨셉 확정 후 작성한다.
