# 패턴 온 페어리 (Pattern on Fairy) - 마스터 기획 및 기술 명세서

---

## 1. 프로젝트 개요 및 기술 아키텍처

### 1.1 기술 스택 및 구동 환경
* 형태: 단일 파일 웹 애플리케이션 (index.html 내 HTML5 Canvas, Vanilla JS, CSS3 통합).
* 의존성: 외부 JS/CSS 라이브러리 일체 배제 (순수 바닐라 환경).
* 화면 규격: 9:16 모바일 세로 뷰포트 (PC 브라우저 접속 시 화면 중앙 정렬 및 여백 레터박스 처리).
* 데이터 영속성: localStorage를 활용하여 계정 재화, 인벤토리, 장착 장비, 페어리 돌파 단계, 보유 코스튬, 가챠 천장 카운트, 퀘스트 달성 상태, 무한 모드 랭킹(Top 5) 자동 저장 및 복원.
* 오디오 엔진: 외부 음원 파일 의존 없이 Web Audio API(AudioContext, OscillatorNode, GainNode)를 이용한 자체 사운드 신디사이징 (경쾌한 마력 절단음, 타격음, 피격음, 피버 전용 신스 펄스 BGM).

### 1.2 비주얼 톤 앤 매너 (요정 판타지 아케인 스타일)
* 사이버틱 네온 배제: 전선이나 네온사인 느낌을 배제하고 신비롭고 유기적인 요정 마력(Aether / Fairy Mana)과 별빛/룬 문양 비주얼 채택.
* 적용 범위: 본 절은 Canvas 런타임 이펙트(궤적, 노드, 참격, 발광)에 한정한다. 일러스트 에셋(캐릭터/몬스터/배경)의 화풍은 `docs/art_style_guide.md`의 `STYLE_BASE`를 따른다.
* Canvas 렌더링 스타일:
  * 궤적 선: 소프트 블룸(Soft Bloom, 반투명 퍼짐 효과)과 별가루 잔상이 남는 '에테르 스트림(Aether Stream)'.
  * 그리드 노드: 금속성 부품 대신 영롱하게 빛나는 '마력 핵 / 룬 결정체(Runic Crystals)'.
  * 참격 효과: 날카로운 별빛 가루가 호를 그리는 '요정 마력 검기(Arcane Slash)'.
* 등급별 마력 속성 색상:
  * 일반: 성스러운 금빛 (Holy Gold, #FFE600)
  * 중갑/암살: 태양 호박석 (Solar Amber, #FF7A00)
  * 강습: 화염 루비 (Blaze Ruby, #FF2A2A)
  * 보스: 신비로운 무지개 룬 오오라 (Prismatic Rainbow HSL 순환 발광)

### 1.3 에셋 파이프라인 및 Fallback 렌더링 규격
* 에셋 디렉토리: ./assets/ 상대 경로 기준 로드.
* 2중 렌더링 세이프티 (Graceful Fallback):
  * 이미지 로드 성공 시: 캔버스 상에 2.5D 투명 PNG 스프라이트로 렌더링.
  * 이미지 로드 실패 또는 미배치 시: 런타임 에러 없이 내장 Canvas 2D 절차적 벡터 드로잉(arc, lineTo, shadowBlur 소프트 블룸)으로 즉각 대체하여 무중단 플레이 보장.
* 표준 에셋 경로 규격 (분류별 하위 폴더, 에셋별 프롬프트와 생성 상태는 `docs/art_prompts/` 참조):
  * 배경 (공용 스크롤): ./assets/backgrounds/bg_fantasy_scroll.png
  * 스테이지 배경: ./assets/backgrounds/bg_stage_[1~5].png
  * 로비 일상 모션: ./assets/characters/fairy/lobby_fairy_idle_A.png, B.png, C.png
  * 주인공 기본/코스튬 (캐릭터 일러스트): ./assets/characters/fairy/fairy_base.png, ./assets/characters/fairy/fairy_costume_1~6.png
  * 주인공 전투 (2.5D 백뷰): ./assets/characters/fairy/fairy_battle_back.png
  * 동료 컷인/필드: ./assets/characters/partners/cutin_[동료영문명].png
  * 동료 전투 (2.5D 백뷰): ./assets/characters/partners/battle_back_[동료영문명].png
  * 몬스터 폼 스프라이트: ./assets/monsters/monster_[아이디]_form_[A~C].png (아이디는 6.4 참조)
  * 보스 페이즈 스프라이트: ./assets/bosses/boss_[스테이지번호]_phase_[1~3].png (페이즈당 1폼)
  * UI 아이콘: ./assets/ui/
* 모션 구현 방식 (프로토타입):
  * 프레임 시퀀스(스프라이트 시트)를 사용하지 않고, 모션당 단일 이미지 + Canvas 절차적 모션(상하 부유, 호흡 스케일, 좌우 흔들림, 돌진 이동)으로 구현한다.
  * 모션 파라미터(진폭, 주기 등)는 Config 데이터로 분리한다.
  * 추후 확장: 여유 확보 시 날개 등 부위 분리(컷아웃) 레이어 애니메이션으로 전환 검토.

### 1.4 AI 이미지 생성 파이프라인 가이드 (사전 에셋 빌드용)
* 1단계 (노드 궤적 선행 정의):
  * 3×3 그리드에서 몬스터가 취할 노드 궤적을 먼저 확정하고, 이를 캐릭터의 '동세 축(Line of Action)'으로 번역.
  * 예: 3노드 가로 베기 [4-5-6] -> 양 날개를 수평으로 펼친 비행 포즈.
  * 예: 4노드 L자 방어 [1-4-7-8] -> 거대한 타워 실드를 왼쪽에 세우고 몸을 숙인 L자 방어 포즈.
* 2단계 (프롬프트 작성 지침):
  * 프롬프트 키워드, 블록 조합 순서, 시점(View) 규격, 금지 키워드는 `docs/art_style_guide.md`를 따른다.
  * 몬스터는 노드 앵커 매핑을 위해 가이드의 `VIEW_MONSTER`(orthographic 2D front view)를 사용한다.
* 3단계 (인게임 앵커 매핑):
  * 생성된 일러스트의 머리/무기/관절 중심점을 3×3 노드 중심점에 스냅 맞춤.
  * 일러스트 위에 인게임 Canvas가 반투명 에테르 궤적 가이드를 덧씌워 픽셀 오차 보정.
  * 앵커는 몬스터 기준 로컬 3×3 좌표로 정의하며, 필드 그리드 상의 배치 위치와 무관하다 (6.2 참조). 회전/반전 기믹 시 일러스트와 앵커를 함께 변환한다.

## 2. 경제 시스템, 가챠 및 퀘스트

### 2.1 계정 기초 및 장비 시스템
* 시작 지급 재화: 1,000 Gold + 5,000 Gem.
* 장비 5개 부위: 머리, 상의, 하의 (주옵션: 최대 HP), 장갑, 신발 (주옵션: 공격력).
* 초기 장착: 계정 생성 시 전 부위에 일반 등급 1레벨 기본 장비 장착 상태 제공.
* 인벤토리 및 교체: 최대 100칸. 슬롯 터치 시 1:1 맞교체(Swap).
* 장비 등급 및 수치:
  * 일반: 주옵션 +0.5 HP (공격력 부위는 +0.0) / 부옵션 0개 / 판매가 5 Gold
  * 고급: 주옵션 +0.5~1.0 / 부옵션 1개 / 판매가 10 Gold
  * 희귀: 주옵션 +1.0~1.5 / 부옵션 2개 / 판매가 50 Gold
* 부옵션 풀: 공격력(+0.5), 최대 HP(+0.5~1.0), 치명타 확률(+10%~20%), 에너지 획득 효율(+20%~50%), 열정 획득 효율(+25%~50%). (치명타 피해 옵션은 없으며 치명타 시 기본 공격력의 2배 고정)
* 편의 기능: 단일 판매 및 고급 이하 일괄 판매 지원.

### 2.2 가챠 시스템
* 소모 재화: 장비 상자(100 Gold / 10연차 1,000 Gold), 페어리 & 코스튬 소환(100 Gem / 10연차 1,000 Gem).
* 천장 시스템: 50회 천장 (50연속 5성 미등장 시 50회차에 5성 100% 확정 지급).
* 소환 확률 테이블:
  * 5성 페어리 (10%): 카스미, 에이다, 비요른 (각 3.33%)
  * 5성 코스튬 (5%): 황혼의 대마법사, 심연의 처형자 (각 2.5%)
  * 4성 페어리 (72%): 록사나, 카밀라, 카탈리나, 아이아스, 에이린, 셰헤라자드, 알렉세이, 다온 (8인 각 9.0%)
  * 4성 코스튬 (13%): 숲의 순찰자, 견습 기사, 사막 방랑자, 별빛 학도 (각 3.25%)
* 중복 획득 및 페이백:
  * 동료 중복 획득 시 영혼석 지급 -> 1돌파당 스킬 효과 +20% (최대 5돌파).
  * 5돌파 완료 동료 및 기보유 코스튬 중복 획득 시: 4성 20 Gem, 5성 100 Gem 자동 환급.

### 2.3 일일 퀘스트 (프로토타입 전용 무한 순환)
* UI 표기: 상단 배너에 [프로토타입 전용: 무한 반복 가능] 명시.
* 세부 미션:
  1. 오늘의 출석 체크 (접속 즉시 완료 가능): 400 Gem
  2. 스테이지 3회 클리어: 300 Gem
  3. 적 20명 처치: 300 Gem
  4. 올클리어 최종 보너스: 500 Gem + 500 Gold
* 순환 룰: 올클리어 보너스 수령 즉시 카운트가 0으로 리셋되며 무한 재수행 가능.

## 3. UI/UX 및 비주얼 연출 규격

### 3.1 메인 로비 (아웃게임)
* 일상 모션 (랜덤 진입): 메인 화면 진입/복귀 시 3종 모션(낮잠, 마도서 독서, 유영) 중 1종 무작위 재생.
* PC 가상 자이로 시차(Parallax): 마우스 좌표 기준 원경 레이어 +-8px, 중경 페어리 +-16px 역방향 이동으로 깊이감 연출 (모바일 DeviceOrientation 호환).

### 3.2 인게임 3-Tier 화면 레이아웃 (우측 상단 큐 삭제 및 헤더 재정의)
```text
+-------------------------------------------------------------+
| [TOP] 몬스터 필드 (40%)                                     |
|  [STAGE 3]                       TARGET: [ 04 / 10 ]        | <- 진행 헤더
|  TYPE: [강습] 보이드 버그 (5 NODES)                         | <- 위험도 태그
|                                                             |
|                 [ 현재 등장한 몬스터 일러스트 ]             |
|                 - 3x3 룬 결정체 앵커 점유                   |
|                 - 3.0초 서클 공격 링                        |
|                 - 스테이지별 필드 그리드 내 위치 배치 (6.2) |
|                 - 대기 몬스터는 흐림 처리, 앵커 미표시      |
+-------------------------------------------------------------+
| [MID] 플레이어 필드 (25%)                                   |
|  - 2.5D 백뷰 3인 파티: [동료1]    [주인공]    [동료2]       |
|  - 완충 시 동료 신비 오오라 펄스 & 상향 별빛 파티클         |
|  - HUD: 스테이지 타이머(30초), 플레이어 HP, 열정 게이지     |
+-------------------------------------------------------------+
| [BOT] 컨트롤 존 (35%)                                       |
|  - 좌/우: 동료 1, 2 초상화 & 원형 마력 게이지(100)          |
|  - 중앙: 3x3 에테르 드로잉 그리드 (노드 1 ~ 9)              |
+-------------------------------------------------------------+
```

### 3.3 상단 진행 정보 표시 규격
* NEXT 큐 UI 삭제: 실시간 모핑 시스템과의 시선 분산 방지 및 전략적 불일치 해소를 위해 우측 상단 블록 미리보기 큐 일체 제거.
* 일반 모드 표기: TARGET: [ 현재 몬스터 순번 / 총 몬스터 수 ] (예: TARGET: [ 04 / 10 ]).
* 10번 보스 진입 시: TARGET: [ 10 / 10 ] WARNING: BOSS 붉은색 점멸 배너 전환 (보스 등장 연출은 3.5 참조).
* 무한 모드 표기: TARGET: [ WAVE 14 ] (10단위 보스 등장 시 [ WAVE 20 : BOSS ]).

### 3.4 비행 원근 스크롤 및 피격 FX
* 전진 비행 원근 스크롤: 기본 1.0배속, 드래그 슬로우 시 0.75배속, 참격 타임 프리즈 시 0배속, 피버 모드 시 3.0배속 주행.
* 마력 참격 FX: 타격 중심부 별빛 섬광 + 캔버스 +-4px 진동 (0.05초) + CRITICAL 바운스 텍스트.
* 동료 스킬 컷인 (0.35초): 상향 플릭 시 글로벌 정지 + 배경 40% Dim + 동료 일러스트 고속 슬라이드 인 후 마력 탄환 변환 타격.
* 동료 완충 오오라: 에너지 100 달성 시 sin(time) 오오라 발광 및 상향 스파클로 플릭 유도.

### 3.5 보스 등장 및 페이즈 전환 연출
* 보스 등장 연출 (총 약 2.0초):
  * ① 경보 (0.0~0.8초): 화면 Dim, 몬스터 필드 상하단을 가로지르는 진홍/공허 보라색 룬 문양 띠, 중앙 WARNING 점멸, Web Audio 저음 사이렌, 미세 화면 진동.
  * ② 등장 (0.8~1.6초): 어둠 속에서 보스가 확대 상태로 나타나 원래 크기로 안착. 보스 이름 + 별칭 카드 슬라이드 인 (예: 아케인 오버로드 / 공허의 군주).
  * ③ 준비 (1.6~2.0초): 이름 카드 퇴장, 보스 위에 3×3 룬 프레임 조립 후 공격 링 개시.
* 페이즈 전환 연출 (약 0.5초): 섬광 + PHASE N 표기와 함께 보스 페이즈 이미지 교체.
* 공정성 규칙: 연출 중 스테이지 타이머, 콤보 타이머, 공격 링 정지 및 입력 잠금. 에이다 패시브(보스 등장 시 타이머 +2.0초)는 연출 종료 후 적용.
* 무한 모드: 첫 보스는 전체 연출, 두 번째 보스부터 ① 경보만 축약 재생 (약 1.0초).
* 톤: 1.2 비주얼 톤 앤 매너에 따라 아케이드식 노란 경고 줄무늬 대신 룬 문양 띠로 표현. 신규 이미지 없이 보스 이미지 + Canvas 드로잉으로 구현.
* 연출 시간 및 수치는 Config 데이터로 분리한다.

## 4. 전투 시스템 및 입력 메커니즘

### 4.1 드로잉 조작 및 판정
* 슬로우 모션: 드래그 유지 중 전체 속도 0.75배속 감속.
* 에테르 스트림 미러링: 하단 3×3 드로잉 궤적이 상단 활성 몬스터의 3×3 룬 프레임(마력 앵커)에 실시간 동기화. 몬스터 위치가 바뀌어도 입력과 몬스터 프레임의 대응을 설명 없이 인지시키는 핵심 장치.
* 유효 판정 조건:
  * 최소 3개 이상의 노드를 거쳐 터치를 뗐을 때(Release) 판정.
  * 정방향 및 역방향 드로잉 모두 100% 정타 인정.
  * 외곽 대각 도약(Void Diagonal Jump): 중간 경유 노드가 비어있는 경우 대각 건너뛰기 인정.
* 기본 공격력: 0.5 (하트 반 쪽 파괴), 치명타 발동 시 2배(1.0).
* 오입력(Miss) 페널티: 플레이어 하트 1.0 차감 + 콤보 리셋.

### 4.2 콤보 시스템 및 에너지 보너스
* 콤보 유지 제한: 2.0초.
* 콤보 타이머 일시 정지(유예): 타격 성공 후 요정 참격(0.15초)과 모핑 트랜지션(0.10초)이 진행되는 총 0.25초 동안 콤보 타이머 카운트다운 완전 정지.
* 에너지 획득 공식: (20 + 콤보 보너스) * (1 + 장비 에너지 효율).
  * 0~4 콤보: +20 / 5~9 콤보: +21 / 10~14 콤보: +22 / 15 콤보 이상: +23(상한).

### 4.3 몬스터 피격 실시간 모핑 (Morphing on Hit) 및 딜레이 보상
* 모핑 개시 시점: 요정의 돌진 참격 및 피격 이펙트(0.15초)가 완전히 종료되어 요정이 제자리로 복귀하는 순간 모핑 개시 (0.10초 트랜지션).
* 공격 딜레이 보상 (Stagger Delay):
  * 피격 후 몬스터 체력이 남아 모핑할 때, 적의 공격 링 타이머 잔여 시간에 +0.5초 즉시 가산 (최대 3.0초 상한).
  * 새로운 패턴을 눈으로 식별하고 손을 댈 수 있는 안전마진 보장.
* 동적 폼 가중치 추첨 (Dynamic Weight / Soft Pity):
  * 동일한 패턴이 연속으로 등장할 수 있으나, 연속으로 나올수록 다른 폼으로 전환될 확률이 점진적으로 증가.
  * 일반 몬스터 (폼 A, B 2종):
    * 최초/전환 직후: A 50% : B 50%
    * 1회 연속 유지 시: 타 폼 전환 확률 75% / 유지 25%
    * 2회 연속 유지 시: 타 폼 전환 확률 100% (강제 전환 및 연속 카운트 초기화)
  * 중갑/강습/보스 (폼 3종 이상):
    * 연속 등장 시 현재 폼의 추첨 가중치를 절반으로 차감하고 잔여 폼들에 균등 분배. 2회 연속 유지 시 현재 폼 가중치 0% 처리 후 타 폼 중 50:50 추첨.

### 4.4 동료 액티브 스킬 안전 규칙
* 상향 플릭 조작: 1번 동료(1번 노드 위 플릭), 2번 동료(3번 노드 위 플릭). 15.0초 내부 쿨타임.
* 스킬 피격 시 예외:
  * 동료 스킬로 적 체력이 깎일 때는 외형 모핑을 발생시키지 않고 형태 유지.
  * 스킬 발동 후 0.3초 동안 유저의 드로잉 실수로 인한 미스(Miss) 판정 패널티 무효화(Ignore) 처리.

### 4.5 피버 모드 (FEVER! 2단계 시퀀스 & 사운드 정리)
* 발동 조건: 스테이지 사이클당 1회 (열정 100 달성 시).
* 2단계 시퀀스 (총 2.5초):
  * Phase 1 (0.5초 / 피버 인트로): 타임 프리즈 발동, 하단 그리드 페이드아웃, 중앙에 황금빛 FEVER! 바운스 확대, 터치 입력 잠금 (유저 준비 구간). 배경 스크롤 3.0배속 전환.
  * Phase 2 (2.0초 / 3인 합격기 난타): 중앙 TOUCH! 점멸 및 터치 해제. 탭마다 3인 페어리에서 하트 0.5 유도 에너지 볼트 연달아 사출. (피버 중 몬스터 외형 모핑 정지)
* 회복 보너스: 2.0초 내 5회 이상 탭 성공 시 플레이어 하트 1.0 회복.
* 피버 전용 오디오:
  * 피버 진입 즉시 일반 전투 BGM 및 사운드 볼륨 80% 덕킹.
  * 전용 고속 신스 BGM + 탭할 때마다 피치가 점진 상승하는 전용 라이트 볼트 타격음만 단독 출력하여 청각 피로 해소.

## 5. 페어리 11종 상세 스펙

### 5.1 5성 페어리 (3인)
* 카스미 (보라 / 심연): 액티브 - 단일 적 즉사 (보스는 하트 2.0 고정 피해) / 패시브 - 오입력(Miss) 피해 최초 1회 완전 무효화.
* 에이다 (황금 / 시간): 액티브 - 스테이지 타이머 즉시 +5.0초 / 패시브 - 엘리트 및 보스 등장 시 스테이지 타이머 +2.0초.
* 비요른 (진홍 / 화염): 액티브 - 5.0초간 일반 참격 추가 피해 +0.5 / 패시브 - 스킬 직후 첫 일반 참격 치명타 확률 100%.

### 5.2 4성 페어리 (8인)
* 록사나 (분홍 / 관통): 액티브 - 하트 1.0 즉발 관통 피해 / 패시브 - 적 체력 50% 이하 시 플레이어 치명타 확률 +30%.
* 카밀라 (암적 / 흡혈): 액티브 - 하트 0.5 피해 및 플레이어 하트 0.5 회복 / 패시브 - 5.0초마다 하트 0.5 자동 회복.
* 카탈리나 (하늘 / 질풍): 액티브 - 하트 0.5 피해 + 다음 드로잉 유효 판정 시간 2배 / 패시브 - 콤보 단절 시 누적 콤보 50% 보존.
* 아이아스 (강철 / 수호): 액티브 - 하트 0.5 피해 + 0.5초 기절 / 패시브 - HP 0 도달 시 하트 0.5로 생존 및 2.0초 무적 배리어 (전투당 1회).
* 에이린 (녹색 / 치유): 액티브 - 하트 1.0 즉시 회복 / 패시브 - 전투 개시 시 1회 피격 방어 실드 부여.
* 셰헤라자드 (비취 / 충전): 액티브 - 하트 0.5 피해 + 피버 열정 게이지 25% 충전 / 패시브 - 피버 지속 시간 +1.0초 연장.
* 알렉세이 (빙청 / 빙결): 액티브 - 적 1.5초 완전 결빙 (공격 링 동결, 보스 면역) / 패시브 - 드로잉 감속률 10% 추가 (0.65배속).
* 다온 (무지개 / 공명): 액티브 - 다른 슬롯 동료 에너지 20% 즉시 주입 (쿨타임 무시) / 패시브 - 전투 시작 시 본인 에너지 30% 충전 상태 시작.

## 6. 몬스터 밸런스 및 스테이지 설계

### 6.1 등급별 노드 개수 표준화 및 폼 프리셋 규격
* 공격 링 타이머: 전 등급 기본 3.0초 고정.
* 일반 몬스터:
  * 고정 3노드 (체력 0.5 ~ 2.5).
  * 몬스터별 고유 포즈 Form A, B 2종 프리셋 보유.
* 중갑 / 암살 몬스터:
  * 고정 4노드 (체력 1.0 ~ 4.5).
  * 몬스터별 Form A, B, C 3종 프리셋 보유.
* 강습 몬스터:
  * 고정 5노드 (체력 1.5 ~ 6.5).
  * 몬스터별 Form A, B, C 3종 프리셋 보유.
* 보스 몬스터:
  * 체력 감소에 따른 노드 단계 감축 (상태이상 완전 면역).
  * Phase 1 (HP 100%~66%): 7노드 거대 마법진 / Form 1종
  * Phase 2 (HP 66%~33%): 5노드 파츠 파괴 / Form 1종
  * Phase 3 (HP 33%~0%): 3노드 심핵 / Form 1종
  * 최종 보스 예외 (5스테이지): 클라이맥스 연출을 위해 9 -> 7 -> 4 노드.
  * 노드 수 산정: 닫힌 궤적은 시작점 복귀까지 포함하여 센다 (예: 고유 노드 6개 + 복귀 1회 = 7노드).
  * 페이즈당 단일 폼으로 고정하고, 단조로움은 보스별 고유 기믹(6.3)으로 보완한다.
* 궤적 설계 원칙:
  * 직관성: 궤적 모양은 페이즈 이름 및 보스 외형(동세)과 일치해야 하며, 플레이어가 외형을 보고 모양을 떠올릴 수 있어야 한다.
  * 기믹 정합성: 반전/회전 기믹이 적용되는 궤적은 해당 변환에 대해 비대칭이어야 한다. 대칭 궤적은 정/역방향 정답 인정 규칙에 의해 변환 후에도 동일 패턴이 되어 기믹이 무효화된다.

### 6.2 몬스터 필드 그리드 및 위치 규칙
* 좌표 분리 원칙: 몬스터의 노드 궤적은 몬스터 기준 로컬 3×3으로 고정하고, 몬스터 필드 상의 배치 위치만 별도의 필드 그리드 좌표로 관리한다. 플레이어 입력 그리드는 3×3 고정이며 조작 난이도는 변하지 않는다 (위치 변화는 시선 추적 난이도만 추가).
* 필드 그리드 크기:
  * 기본값 6×4 (가로 6 × 세로 4). 9:16 화면의 몬스터 필드(가로 1 : 세로 약 0.71)에서 칸이 정사각형에 가깝다.
  * 스테이지별로 덮어쓰기 가능 (6.3 표). 보스는 별도 그리드를 갖지 않고 해당 스테이지 그리드를 따른다.
  * 칸 크기 = min(필드 가로 ÷ 열 수, 필드 세로 ÷ 행 수)로 항상 정사각형을 유지하고, 남는 공간은 여백 처리한다. 최소 크기는 3×3.
  * 몬스터 크기는 3×3 칸으로 고정되며, 배치 가능 위치는 (열 수 - 2) × (행 수 - 2)곳이다.
* 활성 규칙: 화면에 여러 몬스터가 있어도 공격 대상(활성)은 한 번에 1마리. 대기 몬스터는 흐림 처리하고 3×3 룬 프레임을 표시하지 않는다.
* 표시 규칙: 필드 그리드 자체는 화면에 표시하지 않는 내부 좌표다. 화면에는 활성 몬스터에 부착된 3×3 룬 프레임만 표시하며, 프레임은 입력 그리드와 동일한 노드 디자인을 사용한다.
* 이동 연출: 위치 변경은 순간이동이 아닌 프레임째 미끄러지는 이동으로 표현한다 (오버로드 순간이동 기믹 제외).
* 데이터 검증: 등장 위치, 이동 경로 등 위치 데이터는 로드 시 해당 스테이지 그리드 범위를 검사하고, 벗어나면 범위 내로 보정한다.
* 그리드 크기, 이동 속도, 이동 빈도는 Config 데이터로 분리한다.

### 6.3 스테이지 구성 및 보스 기믹
* 구성 원칙: 보스 컨셉과 기믹을 먼저 정하고, 스테이지 그리드, 배경, 일반/중갑/강습 몬스터를 보스에 맞춰 역산한다. 스테이지마다 일반/중갑/강습/보스 몬스터 각 1종.
* 단계적 학습: 스테이지마다 새 요소를 1개씩 추가하여 별도 튜토리얼 없이 스테이지 진행으로 학습시킨다.

| 스테이지 | 지역 (가칭) | 그리드 | 보스 | 보스 기믹 | 새로 학습하는 요소 |
| :---: | :--- | :---: | :--- | :--- | :--- |
| 1 | 이끼 덮인 고성 정원 | 3×3 | 골렘 타이탄 | 좌우 반전: 무게 중심을 반대쪽으로 옮기며 궤적 좌우 반전 | 기본 규칙 + 첫 기믹 (위치 고정) |
| 2 | 뇌운의 절벽 섬 | 4×3 | 스톰 와이번 | 측면 강습: 화면 밖으로 빠졌다가 반대쪽에서 날아 들어옴. 강습 중 공격 링 단축, 성공 시 추가 피해 및 경직 | 좌우 이동 |
| 3 | 독안개 늪 숲 | 4×3 | 스파이더 퀸 | 매달려 회전: 줄에 매달려 좌우 진자 이동 후 정지 순간 90°/180° 회전 | 좌우 이동 + 회전 |
| 4 | 버려진 연금술 공방 | 5×4 | 키메라 비스트 | 쌍두 연격 + 도약: 사자 머리 공격 후 상하 도약, 뱀 꼬리가 좌우 반전 궤적으로 연속 공격 | 상하 이동 + 연속 2회 |
| 5 | 공허에 잠긴 요정 왕궁 | 6×4 | 아케인 오버로드 | 은폐 + 종합: 필드 곳곳으로 순간이동, 마도서 페이지로 일부 노드 은폐. P3에서 1~4 기믹 무작위 혼합 | 전체 (은폐 난이도는 플레이 테스트 후 조정) |

* 세계관: 공허(Void)가 요정 왕국의 각 지역을 잠식하며, 1~4 보스는 원래 왕국의 존재가 공허에 오염된 형태다. 5스테이지로 갈수록 왕국 중심부에 접근한다.
* 기믹 운용 규칙:
  * 이미지 추가 없음: 회전/반전은 노드 번호 변환 + Canvas 이미지 변환으로 처리하여 페이즈당 이미지 1장을 유지한다.
  * 판정 로직 불변: 목표 노드 변환 또는 표시 방식 변경만 사용한다 (정/역방향 모두 정답 인정 규칙 유지).
  * 발동 주기 제한: 매 타격이 아닌 N회 타격마다 또는 페이즈 전환 시에만 발동.
  * 예고 연출: 발동 약 0.5초 전 예고 모션 표시.
  * 난이도 교환: 궤적이 긴 P1은 기믹을 약하게, 궤적이 짧은 P3는 기믹을 강하게 적용.
  * 입문 예외: 1스테이지 골렘 P3(ㅡ자 심핵)는 좌우 대칭이라 반전 기믹이 무효이므로, 기믹 없이 쉽게 마무리하는 입문 구간으로 둔다.
  * 강습 몬스터 예습: 각 스테이지 강습 몬스터는 해당 스테이지 보스 기믹을 약한 형태로 사용한다. 일반/중갑 몬스터는 기믹 없음.
  * 발동 주기, 예고 시간, 링 단축값 등은 Config 데이터로 분리한다.

### 6.6 무한 모드 (Endless Mode) & 로컬 랭킹
* 진행 방식: 10의 배수 웨이브마다 보스 출현, 그 외 웨이브는 전 몬스터 무작위 생성.
* 필드 그리드: 최대 그리드인 6×4 고정 (전 스테이지 몬스터가 혼합 등장하므로).
* 스탯 스케일링 공식 (Tier = Math.floor(Kills / 10)):
  * 일반몹 체력: 1.0 + (0.5 * Tier)
  * 중갑/강습 체력: 2.5 + (1.0 * Tier)
  * 보스 체력: 10.0 + (3.0 * Tier)
  * 공격 피해량: Tier 0~2(일반 1.0 / 보스 2.0), Tier 3~5(일반 1.5 / 보스 3.0), Tier 6 이상(일반 2.0 / 보스 4.0).
* 기록 관리 (localStorage): 상시 최고 킬 수 노출, 최근 Top 5 기록 팝업 뷰어(순위, 킬수, 편성 동료, 획득 골드, 일시). 종료 시 1킬당 10 Gold 정산.
